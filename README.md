# Видеоцех: медиа

Файлы для набора «Видеоцех». Установщик и обновление набора скачивают их сами: руками ничего делать не нужно.

Файлы лежат на странице релизов этого репозитория. Каждый выпуск медиа — отдельный релиз `media-ГГГГ.ММ.ДД`; набор проверяет контрольную сумму каждого архива.

| Архив | Что внутри | Происхождение и лицензия |
|---|---|---|
| `kadr-media-2026.10.24.zip` | 20 музыкальных треков, 186 наклеек, 52 фона, 50 картинок «Мультика» в гуаши | Сгенерировано для Видеоцеха: музыка — Suno через Kie.ai, картинки — модели Kie.ai и Krea. Входит в набор для роликов покупателя |
| `sounds-2026.10.25.zip` | 1.139 звуков для роликов | CC0: Kenney (kenney.nl) и Freesound; авторы перечислены в `CREDITS.md` внутри архива |
| `polka-3d-2026.10.25.zip` | 14 3D-объектов для Блендера | Собраны в Блендере из моделей и фактур Poly Haven и Human Base Meshes (CC0); подробности в `ЛИЦЕНЗИИ.txt` внутри архива |

Модель распознавания речи (whisper.cpp, `ggml-large-v3-turbo.bin`) набор скачивает с Hugging Face: `huggingface.co/ggerganov/whisper.cpp`, лицензия MIT.
